# Instrucciones para Codex

Esta web se reconstruye desde cero usando /reference/plantilla.mhtml como referencia visual principal.

Reglas:
- Antes de modificar código, revisar docs/visual-spec.md.
- No implementar funcionalidades nuevas no solicitadas.
- Mantener componentes pequeños y reutilizables.
- Priorizar fidelidad visual.
- Después de cada cambio importante, explicar qué archivos se han tocado.
- Si falta información visual, pedir o consultar capturas en /reference/screenshots.
